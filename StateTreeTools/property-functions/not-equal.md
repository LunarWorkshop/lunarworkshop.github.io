# !=

**Plugin:** StateTreeToolsCore
**Category:** Math \| Float

Returns `true` if **Left** and **Right** are not exactly equal. As with [==](/StateTreeTools/property-functions/equal), floating-point precision means two values that are mathematically equal may not compare as equal; use [Nearly Equal](/StateTreeTools/property-functions/nearly-equal) when an approximate comparison is more appropriate.

---

## Configuration

### Left
The value on the left-hand side of the comparison.

### Right
The value on the right-hand side of the comparison.

### Result
`true` if **Left** != **Right**, otherwise `false`.

## Unreal Engine Version Notes

Property functions are not available in UE 5.4. This node requires **UE 5.5 or later**.
