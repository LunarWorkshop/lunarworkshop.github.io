# Gameplay Attributes

Property functions for reading Gameplay Ability System (GAS) float attributes from an actor's Ability System Component. **Requires UE 5.5+ and Unreal's built-in Gameplay Abilities plugin to be enabled.**

| Property Function | Description |
|-------------------|-------------|
| [Get Float Attribute](/StateTreeTools/property-functions/get-float-attribute) | Read the current (modified) value of a float attribute |
| [Get Float Attribute Base](/StateTreeTools/property-functions/get-float-attribute-base) | Read the base (unmodified) value of a float attribute |
