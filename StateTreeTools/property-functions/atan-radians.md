# Atan (Radians)

**Plugin:** StateTreeToolsCore
**Category:** Math \| Float

Returns the arctangent (inverse tangent) of a value, expressed in radians. Unlike [Atan2 (Radians)](/StateTreeTools/property-functions/atan2-radians), this takes a single ratio rather than separate Y and X components, so it cannot distinguish the quadrant of the original angle.
